Getting Started

Welcome to the OrbisPanora library documentation. This library provides tools for parsing and visualizing Minecraft Anvil (.mca) files.

What is an MCA File?

MCA (Minecraft Anvil) files are the region file format used by Minecraft to store chunks of the game world. Each file contains a 32x32 grid of chunks.

Installation

npm install orbispanora

Or using yarn:

yarn add orbispanora

Usage

Import the library and initialize the visualizer:

import { OrbisPanora } from 'orbispanora';

const visualizer = new OrbisPanora();
visualizer.load('path/to/file.mca');

API Reference

OrbisPanora

Main class for handling MCA files.

Methods

  • load(filePath: string): Promise<void> - Load an MCA file
  • render(canvas: HTMLCanvasElement): void - Render to canvas
  • getChunk(x: number, z: number): Chunk - Get specific chunk data

Examples

Basic Loading

const visualizer = new OrbisPanora();
await visualizer.load('world/region/r.0.0.mca');
visualizer.render(canvas);

Advanced Configuration

const visualizer = new OrbisPanora({
  renderDistance: 16,
  quality: 'high',
  enableLighting: true
});

Troubleshooting

File not loading

Ensure the file is a valid MCA format and not corrupted.

Performance issues

Try reducing the render distance or quality settings for better performance.
