API Documentation

REST API endpoints for OrbisPanora

Files

POST
/api/files/upload

Upload an MCA or ZIP file for processing

Request Body

{
  "file": "binary data",
  "format": "mca" | "zip"
}

Response

{
  "id": "uuid",
  "status": "processing",
  "createdAt": "timestamp"
}
GET
/api/files/:id

Get file processing status and metadata

Response

{
  "id": "uuid",
  "status": "completed",
  "metadata": {
    "chunks": 1024,
    "size": "32MB"
  }
}
DELETE
/api/files/:id

Delete a processed file

Response

{
  "success": true,
  "message": "File deleted successfully"
}

Chunks

GET
/api/chunks/:fileId/:x/:z

Get specific chunk data from a file

Parameters

  • fileId - File UUID
  • x - Chunk X coordinate (0-31)
  • z - Chunk Z coordinate (0-31)

Response

{
  "x": 0,
  "z": 0,
  "blocks": [...],
  "heightMap": [...]
}
GET
/api/chunks/:fileId/all

Get all chunks metadata from a file

Response

{
  "total": 1024,
  "chunks": [
    { "x": 0, "z": 0, "size": "4KB" },
    ...
  ]
}

Render

POST
/api/render/:fileId

Generate a rendered image of the world

Request Body

{
  "width": 1920,
  "height": 1080,
  "quality": "high",
  "perspective": "isometric"
}

Response

{
  "imageUrl": "url",
  "format": "png",
  "size": "2.5MB"
}
